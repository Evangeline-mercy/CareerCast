9. SKILL GAP ANALYSIS
------------------------------------------------------------------------------------------
The recommendation system compares candidate skills with the required skills associated with each recommended career.

Matched skills are reported separately from missing skills, allowing the system to provide career-specific upskilling information.

10. VALIDATION INTERPRETATION
------------------------------------------------------------------------------------------
The external validation produced a Top-1 accuracy of 70.00% and a Top-3 accuracy of 90.00%.

Top-3 accuracy is particularly useful for a career recommendation system because multiple career paths can reasonably match the same candidate profile.

The external validation results should be considered more representative of generalization than the internally generated synthetic profile test set.

11. CURRENT LIMITATIONS
------------------------------------------------------------------------------------------
1. The training profiles are generated through controlled skill variations from predefined career profiles.
2. The internal test accuracy is therefore not equivalent to real-world deployment accuracy.
3. External validation currently contains 10 curated candidate profiles.
4. Some careers have overlapping skill requirements, which can cause similar careers to appear in the Top-5 results.
5. Additional real-world candidate profiles would strengthen future validation.
